### Page Structure

Let's start by building a site of pages, each populated with the citable tokens from one of the chunk files in, for example, `editions/html/Aristophanes_Frogs/pages` (this location is defined in `scripts/config.toml`).

There is a template for a reader-page at `editions/templates/reader_page.html`.

In the text-body, tokens will be displayed, using html and CSS, formatted as readers expect:

- Prose will be in paragraphs, by citable unit.
- Poetry will be in poetic lines (the citable unit).
- Drama will be in poetic lines, with speaker-attribution (but this is tricky… see below).

Each token will be wrapped in an HTML element that contains an ID, its token-level CTS-URN. Something like.

  <span class="text_token" data-ctsurn="urn:cts:greekLit:tlg0019.tlg009.fu.sp:1.1.text.token.1">Εἴπω</span>

All the text-tokens should be organized and displayed inline, grouped according to traditional citation. 

**To make this easier and less error-prone, I have added an entry in `config.toml`, `["input"]["citation_level"]`. For drama and poetry, it will usually be 1; for Herodotus and many other prose works, it may be 2.**

`["input"]["citation_level"]` can determine how inline tokens can be grouped as a block for display. Tokens belong to the same citation-unit if the left-most N elements of the citation-field of the CTS is the same.


In the above example, a drama, which is cited by poetic line, `citation_level = 1` (the leftmost element of "1.1.text.token.1").

For Herodotus, cited "book.section", a token might appear as:

  <span clas="text_token" data-ctsurn="urn:cts:greekLit:tlg0016.tlg001.grc:1.137.token.50">ἀδικήματα</span>

For this text `citation_level = 2`, so all tokens shaing "1.137" belong in a block.

It would be nice to have the citation-value on the screen, perhaps in a contrasting color, before the text. So a section of Herodotus would have "1.137" as the first thing, with some nice white-space around it.

An attempt I made at this kind of thing a few years ago might be a useful example, at least for how the text of a poem, built from citable tokens, appears: <https://furman-university-editions.github.io/Readers/Homeric_Hymns/Demeter_1-50.html>

When we dig deeper into CSS later, we can fine-tune display, but I mention all this to guide how the text part of the page is structured.
