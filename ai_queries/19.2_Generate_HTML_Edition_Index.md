### Site Structure and Navigation

The next step is to start building HTML pages!

The html pages for this text's site will go in `["output"]["html_output_dir"]`, in a sub-directory named `["input"]["file_name"]`, in a sub-directory named `"pages"`.

One html file for each chunk. The files should be named with `["input"]["filename"]` + a citation-range + `.html`, based on the chunk.

That is, if one chunk starts with `urn:cts:greekLit:tlg0019.tlg009.fu.sp:209` and ends with `urn:cts:greekLit:tlg0019.tlg009.fu.sp:239`, the filename would be `Aristophanes_Frogs_209-239.html`.

If a chunk starts with `urn:cts:greekLit:tlg0016.tlg001.grc:1.0` and ends with `urn:cts:greekLit:tlg0016.tlg001.grc:1.1`, the filename would be `Herodotus_1.0-1.1.html`. If it contains only `urn:cts:greekLit:tlg0016.tlg001.grc:1.2`, the filename should be `Herodotus_1.2.html`.

As you will see from templates, that "citation-range" will get used a few times in the content of the page.

There are two template files in `["output"]["html_template_dir"]`. One for building the `index.html` page, and one for each of the content-pages (this template is called `reader_page.html`).

### The Index Page

For the moment, let's just get an index page built!

There should be an `index.html` file in the directory named `["output"]["html_output_dir"]`, in a sub-directory named `["input"]["file_name"]`. 

The index file will contain a little front-matter, with some kind of table of contents. 

The function for generating the Table of Contents will be driven by the chunked `.txt` files in `["output"]["html_temp_dir"]` and should be cleanly separated, since there will probably be usability considerations that we want to tweak. For example, a TOC for the Herodotus will be very, very long, and we might want the option to include collapsing it by book.

The index page should have a "forward" link that goes to the first chunk. 

As part of the navigation, let's have a link like: `<a href="../index.html">Editions Home</a>`.
